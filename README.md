# The Funniest AI Excuse

A tiny Python program that writes the funniest one-line excuse an AI agent could give after failing a task — a single line of at most 200 characters — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

It creates `/output` if needed and writes the excuse as the only line of `/output/entry.txt`.
